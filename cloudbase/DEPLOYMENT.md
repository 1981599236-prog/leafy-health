# 部署到腾讯云 CloudBase（图形界面步骤）

## 为什么要这样做

“静态网站托管”可以理解为腾讯云替你存放和公开网页文件的地方。网页、登录与数据库都在 CloudBase 中，手机访问时不用再跨到 Vercel。

## 在控制台操作

1. 左侧点击 **静态网站托管**。如果是第一次使用，先按提示开通。
2. 选择 **Git 仓库部署**（名称可能显示为“GitHub 仓库”或“代码仓库部署”）。
3. 授权 GitHub 后选择：
   - 仓库：`1981599236-prog/leafy-health`
   - 分支：`main`
4. 在构建设置里填入：
   - 安装命令：`npm install`
   - 构建命令：`npm run build`
   - 输出/发布目录：`out`
5. 点击部署，等待状态显示“成功”。
6. 打开部署结果提供的默认网站地址（通常以 `tcloudbaseapp.com` 结尾），用它来注册、登录和记录健康数据。

> `out` 是构建后生成的网页成品文件夹；CloudBase 只需要把它发布到网站地址上。

## 后续更新

以后功能改完后，在 GitHub Desktop 点击 **Push origin**。CloudBase 若启用了自动部署，会自行更新；若没有自动部署，在静态网站托管页面点击一次“重新部署”即可。
