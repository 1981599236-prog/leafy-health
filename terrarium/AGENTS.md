# Terrarium Asset Rules

## Scope

These rules only apply to terrarium related tasks.

Do not apply these rules to other application modules.

---

# Goal

Create a modular 2D terrarium asset system.

Users can unlock assets and freely arrange them into their own miniature ecosystem.

All generated assets must be reusable, composable, and suitable for scene building.

---

# Asset Categories

## 1. Background

Purpose:
Create atmosphere and environment.

Examples:
- dark gradient background
- forest shadow background
- soft texture background
- mist background

Rules:
- Complete background image
- No main objects
- Minimal details
- Low contrast
- Calm atmosphere

---

## 2. Elements

Purpose:
Independent objects users can freely place.

Examples:
- plants
- flowers
- mushrooms
- trees
- rocks
- branches
- magical plants

Rules:
- One independent object per asset
- No complete scene
- No unrelated objects
- Must be reusable standalone asset

Style:
- 2D illustration
- Flat color blocks
- Soft hand-drawn edges
- No 3D
- No realistic lighting

Perspective:
- Front or side view
- Weak perspective
- Avoid strong top view

---

## 3. Ground

Purpose:
Base layer for the scene.

Examples:
- soil
- grass
- stone ground
- water
- moss

Rules:
- Independent ground module
- Used as bottom layer
- Slight top view allowed

---

# Global Style Rules

All terrarium assets must maintain:

- Same visual world
- Same illustration style
- Same perspective system
- Same color system

---

# Color Rules

Allowed:
- Different hues

Must keep:
- Similar saturation
- Similar brightness range

Avoid:
- Neon colors
- Extremely bright colors
- Extremely dark colors
- Random style differences

---

# Generation Principles

Background creates atmosphere.

Ground creates foundation.

Elements create the scene.

All assets should support:
- Drag and drop
- Scaling
- Free composition
- User customization
