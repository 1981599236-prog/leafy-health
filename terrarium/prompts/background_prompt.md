# Background Prompt Template

```text
Create one complete 2D terrarium background: [environment / atmosphere].

Style: calm flat-color illustration, soft hand-drawn edges, weak perspective,
low contrast, subdued color palette, consistent with a modular miniature
ecosystem game.

Composition: leave open negative space for draggable foreground assets;
include no central hero object, no characters, no plants that read as separate
collectible elements.

Output: [aspect ratio], complete background only, no text, no frame, no UI,
no 3D render, no photorealistic lighting, no neon colors.
```

Replace bracketed text before use. Choose a single atmosphere per generation.
