# Ground Prompt Template

```text
Create one modular 2D terrarium ground asset: [soil / moss / water / stone].

Style: flat color blocks, soft hand-drawn edges, calm low-contrast palette,
slight top view allowed, consistent with a modular miniature ecosystem game.

Composition: a clean independent base layer with open room for draggable
elements above it; horizontally composable or easy to crop and scale.

Output: [aspect ratio], ground module only, no characters, no main plants,
no text, no frame, no 3D render, no photorealistic lighting, no neon colors.
```

Replace bracketed text before use. Keep each generated ground type separate.
