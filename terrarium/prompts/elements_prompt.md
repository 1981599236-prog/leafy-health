# Elements Prompt Template

```text
Create one standalone 2D terrarium game asset: [single object].

Style: flat color blocks, soft hand-drawn edges, weak front or side
perspective, subdued palette, consistent with a calm miniature ecosystem.

Composition: exactly one independent object, centered, fully visible, with
clear silhouette and comfortable padding. It must be suitable for drag, drop,
scaling, and layering in a scene.

Output: transparent background PNG, no ground, no full scene, no unrelated
objects, no text, no frame, no 3D, no photorealism, no strong top view,
no neon colors.
```

Replace `[single object]` with one object only, for example `a small mossy rock`.
